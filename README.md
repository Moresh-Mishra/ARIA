ARIA: Autonomous Reasoning & Intelligence Assistant
ARIA is a automated personalized assistant that is used to increase the efficiency of a user by automating the repetitive tasks and by providing the relevant information in the required format.
ARIA uses Laya as its prime decision engine which helps it to make afaster and efficent decision making.
ARIA has a LLM API-key based architecture that have conversational onterface that helps to converse.
